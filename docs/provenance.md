# Provenance

Every file in this repository that was ported from
[`open-rfc`](https://github.com/marianfoo/open-rfc) is listed here with the
exact upstream file and commit it came from, and what changed in translation.

This table exists for two reasons. Apache License 2.0 §4(b) requires prominent
notices stating which files were changed. And it is the index used to propagate
an upstream fix: when open-rfc changes `src/protocol/ni.ts`, this table says
which Go file to look at, and the recorded commit says how far behind we are.

Upstream baseline: `847036dce5e29015bbc266a4d19cc9c15295a831` (open-rfc 0.2.3).

To check whether a ported file has drifted, with an open-rfc checkout alongside
this one:

```sh
git -C ../open-rfc log --oneline 847036d..origin/main -- src/protocol/ni.ts
```

## Not ported, deliberately

| Upstream | Why |
|---|---|
| `src/compat/**` | Exists to be bug-compatible with the archived `node-rfc` npm package and with `@sap/cds-rfc`. Neither has a Go consumer. |
| `src/compat/node-rfc-public-surface.ts`, `src/client/rfc-errors.ts` | The only upstream files containing third-party (SAP SE, `node-rfc`) code. Because they are not ported, this repository carries no `THIRD_PARTY_NOTICES.md`; if either is ever ported, that file and its Apache-2.0 attribution to SAP SE must come with it. |
| `src/protocol/bytes.ts` intrinsic helpers (`intrinsicUint8ArrayByteLength`, `intrinsicUint8ArrayView`, `snapshotUint8Array`) | Defend against JavaScript callers that override `Uint8Array` geometry accessors. Go slices expose no user-overridable geometry, so the entire class of attack is absent. The *intent* — never alias caller memory — is preserved by copying in `wire.NewReader`, `wire.Writer.Finish`, and the NI layer's `EncodeFrame`/`Push`. (The file's `CheckedByte*` classes *are* ported; see the ported table.) |
| `test/ni.test.ts`, case "encodes from intrinsic typed-array geometry" | Tests the above. No Go analogue is possible; `internal/ni/frame_test.go` covers the underlying intent with `TestEncodeFrameDoesNotAliasCallerPayload`. |
| `src/values/rfc-value-snapshot.ts` (+ `test/rfc-value-snapshot.test.ts`) | The value-layer twin of the `bytes.ts` geometry defense: it deep-copies a caller-supplied JavaScript value tree while rejecting proxies, getter traps, and cycles and enforcing node/byte/array budgets. Go callers pass typed values (structs, maps, slices), not proxy-trapped objects with accessors, so the entire attack class is absent. The *intent* — never retain or alias caller-owned memory, and bound sizes — is preserved by the encoders copying at their boundaries and by the existing wire limits. |
| `src/values/classic-bcd.ts` (+ `test/classic-bcd.test.ts`) | A node-rfc output-representation selector (`"string"` / `"number"` / a caller converter function) plus its error wrapper. Go has no node-rfc consumer: decoded BCD and decimal-float values are returned as precision-preserving decimal strings (see `packed_decimal.go`, `decimal_float.go`), and a caller converts to float64 or a decimal type itself. The mode/converter facade has no Go analogue. |
| `src/values/classic-int8.ts` | A representation selector converting the exact INT8 wire integer to/from `number` / `bigint` / `string` for a node-rfc caller. Go represents INT8 as its native `int64`, whose range is the type, so the mode machinery and the safe-integer/canonical-string guards collapse into the type. The 8-byte little-endian read/write itself lives in the structure codec (milestone tail, behind M4). |
| `src/metadata/immutable-map.ts` (+ its `isImmutableMetadataMap` trust predicate) | A wrapper that hides a `Map` behind private state because `Object.freeze(new Map())` stays mutable through `Map.prototype.set()`, plus a trust predicate for the (dropped) `rfc-value-snapshot` walk. Go gives immutability by keeping a native `map` in an unexported struct field with no exported mutators, so the wrapper has no Go analogue; metadata snapshots hold their entries in plain Go maps. |
| `test/modern-recursive-metadata.test.ts` | Tests `src/compat/modern-metadata.ts` (`toModernRfcMetadataFromRecursiveGraph`), the node-rfc-shaped projection of the recursive graph. `src/compat/**` is out of scope (no Go consumer), so this test has no Go analogue; the recursive-metadata core is covered by `test/recursive-metadata.test.ts`. |

## Rules for adding to this table

- A ported file carries an SPDX header naming its upstream file and commit.
- A file with no upstream counterpart carries an SPDX header and no provenance
  line; it is original work.
- Record the commit you actually read, not `main`.
