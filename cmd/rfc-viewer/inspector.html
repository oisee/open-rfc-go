RFC Wire Inspector.

Reads an annotated capture from rfc-viewer -json and draws the SAP classic-RFC conversation as a sequence between the client and the application server — gateway handshake, APPC records, and reassembled CPIC/CALL FUNCTION requests and responses. Scalar values stay redacted unless the capture was produced with -values.

Frames are decoded by the same Go stack that speaks the protocol (internal/gateway · appc · cpic · rfcserver · classicrfc). A capture may contain credentials and application data — treat capture files as sensitive.
